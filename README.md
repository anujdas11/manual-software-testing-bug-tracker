# Web Application Manual Testing & Bug Tracker

## 📌 Project Overview
This repository contains a structured manual testing bug report and test cases conducted on web applications, focusing on functional testing, UI/UX consistency, and input validation.

## 🛠️ Testing Scope & Techniques
- **Testing Types:** Functional Testing, Usability Testing, UI/UX Cross-Browser Validation, Form Verification.
- **Defect Tracking Parameters:** Bug ID, Summary, Module, Severity, Priority, Steps to Reproduce, Expected vs. Actual Result.

## 📂 Repository Contents
- `Bug_Tracker.xlsx`: Complete test execution sheet with defect classifications and test scenarios.
